# Hirkan 1.0.0

پنل مستقل هیرکان برای مدیریت کاربران، اشتراک‌ها و نودهای Xray، با رابط فارسی و انگلیسی و تم روشن و تاریک.

**وضعیت: نسخهٔ اولیه، مناسب ارزیابی.** اتصال به باینری واقعی Xray و استقرار روی سرور در این انتشار آزمایش نشده است. این نسخه معادل کامل هیچ پنل دیگری نیست.

## امکانات پیاده‌شده

- راه‌اندازی اولین مدیر، ورود، خروج، نقش مدیر و مشاهده‌گر، نقش‌های سفارشی و کلید API
- کاربران با محدودیت حجم و انقضا، توقف، فعال‌سازی و عملیات گروهی
- گروه‌ها، هاست‌ها، قالب‌های قابل اعمال به کاربر، تنظیمات هسته و نودها
- لینک‌های VLESS، VMess، Trojan و Shadowsocks؛ اشتراک base64، متن، JSON و YAML
- عامل نود برای دریافت تنظیمات، بازراه‌اندازی Xray، گزارش مصرف و دریافت لاگ
- ثبت رویدادهای مدیریتی، آمار سیستم، آرشیو JSON و پشتیبان SQLite
- اعلان HTTP و Telegram و بازنشانی دوره‌ای مصرف

## راه‌اندازی پنل

نیازمندی: Docker Engine و Docker Compose. سورس را دریافت کنید:

```bash
git clone https://github.com/HirkanPanel/panel.git
cd panel
bash install.sh
```

پنل به‌صورت پیش‌فرض فقط روی `127.0.0.1:8000` در دسترس است. پیش از عمومی کردن، از رایانهٔ خود تونل SSH برقرار کنید:

```bash
ssh -L 8000:127.0.0.1:8000 USER@SERVER
```

سپس `http://127.0.0.1:8000` را باز کنید و اولین مدیر را بسازید. رمز حداقل ۱۲ کاراکتر باشد. برای دسترسی عمومی، reverse proxy با گواهی HTTPS معتبر نصب کنید؛ ابتدا ایجاد مدیر را تکمیل کنید. در بخش تنظیمات، مقدار `public_url` را برابر آدرس HTTPS پنل قرار دهید.

```bash
docker compose logs --tail=100 -f
docker compose down
docker compose up -d --build
```

اطلاعات در `data/hirkan.sqlite3` ذخیره می‌شوند. توقف سرویس اطلاعات را حذف نمی‌کند. فایل `.env`، پایگاه داده، توکن نود و خروجی پشتیبان را در مخزن عمومی قرار ندهید.

### اجرای بدون Docker

Python 3.12 یا جدیدتر:

```bash
python3 -m venv .venv
. .venv/bin/activate
pip install -r requirements.txt
python main.py --port 8000
```

## راه‌اندازی نود

Xray را از انتشار رسمی `https://github.com/XTLS/Xray-core/releases` متناسب با سیستم خود نصب کنید. باینری Xray همراه این مخزن نیست. ابتدا در پنل یک نود ایجاد کنید و شناسه و توکن آن را دریافت کنید. یک رکورد هستهٔ Xray با `node_id` همان نود و پیکربندی JSON بسازید. پیکربندی باید شامل inbound معتبر و تنظیمات TLS/Reality مورد نیاز باشد؛ مقدار `clients` توسط پنل ساخته می‌شود. پورت 10085 مخصوص آمار داخلی است و نباید در inbound سفارشی تکرار شود.

روی نود سورس را دریافت و وابستگی‌های Python را نصب کنید، سپس متغیرها را تنظیم کنید:

```bash
export HIRKAN_PANEL_URL=https://panel.example.com
export HIRKAN_NODE_ID=YOUR_NODE_ID
read -rs -p 'Node token: ' HIRKAN_NODE_TOKEN
export HIRKAN_NODE_TOKEN
export HIRKAN_XRAY_BIN=/usr/local/bin/xray
python agent.py
```

برای اجرای مداوم از systemd استفاده کنید و متغیرها را در فایل محیطی با دسترسی 600 ذخیره کنید. عامل، تنظیمات را پیش از اعمال با خود Xray اعتبارسنجی می‌کند. تغییر تنظیمات باعث بازراه‌اندازی هسته و قطع اتصال‌های جاری می‌شود. هماهنگ‌سازی و اعمال محدودیت مصرف در چرخه‌های ۱۵ ثانیه انجام می‌شود؛ مصرف دقیقاً در مرز حجم قطع نمی‌شود.

هاست‌ها، آدرس و پورت اتصال کاربران را تعیین می‌کنند؛ آن‌ها را با inbound نود هماهنگ کنید. برای نمونه، یک هاست VLESS/TCP با همان پورت و تنظیمات امنیت inbound ایجاد کنید. اشتراک کاربر را از جدول کاربران دریافت کنید.

## قالب کاربر

در بخش قالب‌ها، پیکربندی را به شکل JSON ثبت کنید، مثلاً:

```json
{"data_limit": 10737418240, "duration_days": 30, "reset_period": "none"}
```

حجم در قالب بر حسب بایت است. `duration_days` از زمان ساخت کاربر محاسبه می‌شود. هنگام افزودن کاربر، قالب را از فهرست انتخاب کنید؛ مقادیر فرم پر می‌شوند و قبل از ذخیره قابل تغییرند. گروه‌ها و نود هسته نیز از فهرست انتخاب می‌شوند. هر کاربر شناسه و لینک اشتراک تازه دریافت می‌کند. API ساخت کاربر هم `template_id` می‌پذیرد؛ مقادیر صریح درخواست بر قالب اولویت دارند.

## API و آزمایش

مستندات API در `/docs` قرار دارد. درخواست‌های مدیر به `Authorization: Bearer TOKEN` نیاز دارند. توکن ورود از `/api/auth/token` گرفته می‌شود.

```bash
pytest -q test_panel.py
node --check app.js
```

## محدودیت‌های این انتشار

- هستهٔ قابل مدیریت تنها Xray است؛ WireGuard و Hysteria2 پیاده‌سازی نشده‌اند.
- مهاجرت پایگاه دادهٔ پنل‌های دیگر، اتصال ربات مدیریتی، کنترل HWID و اشتراک sing-box پیاده‌سازی نشده‌اند.
- چند پردازش هم‌زمان پنل و چند عامل روی یک نود پشتیبانی نمی‌شوند؛ مصرف و وظایف دوره‌ای برای یک پردازش طراحی شده‌اند.
- سازگاری همهٔ انتقال‌ها و خروجی YAML با همهٔ کلاینت‌ها تأیید نشده؛ قبل از فروش سرویس با کلاینت هدف آزمایش کنید.
- پشتیبان SQLite شامل حساب‌ها و اسرار است. فقط آرشیو JSON همین نسخه را با API import بازیابی کنید؛ فایل پایگاه دادهٔ محصول دیگری سازگار نیست.
- این انتشار هنوز ممیزی امنیتی و آزمایش عملی روی نود واقعی ندارد.
